# 2026-2027-Firmware

This is the software that runs the on-car parts of the telemetry system for the Baja Wildcat Racing car.

This is from the 2026-2027 Baja SAE season.

The webapp (telemetry viewing and storage) can be found [here](https://github.com/UofA-BAJA/2025-2026-webapp).

Check out the 'doc' (documentation) folder in order to get started!
